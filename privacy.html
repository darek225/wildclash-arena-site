Privacy Policy — WildClash Arena

Last updated: October 1, 2026

The WildClash Arena application ("the app") is a desktop uploader tool operated by the owner of the WildClash Arena YouTube channel (@WildClashArenaHQ). The app is used by one person — the channel owner — to publish the channel's own videos. It is not offered to the public as a service.

Google user data the app accesses

Through the YouTube Data API v3, with the owner's authorization, the app accesses only the owner's own YouTube channel, using these scopes:

  • youtube.upload — upload and publish video files and their titles, descriptions, and tags to the owner's channel.
  • youtube.force-ssl — post and manage comments on the owner's own videos (for example, pinning the "tomorrow's fight" comment).

The app does not access any other Google account data, and it does not collect data about viewers or any third party.

How the data is used

Channel data is used solely to publish the channel's own videos and comments at the owner's direction. There is no advertising, profiling, analytics resale, or any other use.

Storage and sharing

OAuth tokens are stored locally on the owner's own computer. They are not transmitted to any server other than Google's own API endpoints, and no Google user data is sold, rented, or shared with any third party.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Revoking access immediately stops the app from using the channel. Locally stored tokens are deleted on revocation or on request.
